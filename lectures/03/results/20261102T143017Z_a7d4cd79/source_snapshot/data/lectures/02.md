# 第2回 ファインチューニングとLoRA

## この回のねらい

- 事前学習とファインチューニングの違い、ファインチューニングが向く場面と向かない場面を理解する
- LoRAの考え方を理解し、Google Colab上で小さなモデルをLoRAで学習させる

## 要点

1. **事前学習とファインチューニング**：事前学習で汎用的な言語能力を身につけたモデルを、目的に合うデータで追加学習させるのがファインチューニング。
2. **向く場面・向かない場面**：出力形式や口調、特定タスクの振る舞いを身につけさせるのに向く。新しい事実や頻繁に変わる情報は、ツールや外部データで参照させるほうが向くことが多い。
3. **SFT**：入力と望ましい出力のペアで学習させる。データの質と形式が結果を大きく左右する。
4. **PEFTとLoRA**：全パラメータを更新せず、小さな低ランク行列だけを学習する。必要なGPUメモリと保存容量を大きく減らせる。主なハイパーパラメータはランク r、学習率、エポック数。
5. **QLoRAとの関係**：QLoRAはベースモデルの重みを4bitに量子化して保持し、その上でLoRAのアダプタだけを学習する方法。重みのメモリが減る一方、学習は速くならず、量子化の誤差で出力が変わることがある。演習ではモデルがT4に載るためLoRAで学習し、4bitで読み込んだときの違いは発展で確かめる。
6. **過学習に注意**：学習に使わない検証データで性能を確かめる。

## 演習で体験すること

- Colab上で小さなモデル（Qwen3.5-0.8B）を架空FAQのデータでLoRA学習させ、JSON形式の遵守率と内容正解率を学習前後で比べる
- 形式は学習で身につくが、FAQにない質問への判断（確認を求めるか断定するか）までは保証されないことを確かめる
